After installation

Run sshworkspace setup once, then register the binary as a local stdio MCP server where that connection type is supported. To switch gateway modes, use sshworkspace gateway client or sshworkspace gateway central HTTPS_URL.

Security requirements

OS and browser authorization is mandatory. This page never executes downloads or remote commands silently. Only verified, publisher-signed installers should be offered as production one-click packages; development artifacts are unsigned.
